Strategy Without PassRole
If you're trying to avoid granting PassRole for security reasons, here’s how you might work around it:

Pre-provision service roles (e.g., CodePipelineServiceRole, CodeBuildServiceRole).

Ensure these roles have correct trust policies (for codepipeline.amazonaws.com or codebuild.amazonaws.com).

Let IAM role reference those roles by ARN in pipeline/build project creation.

Do not allow users modify the role field, and skip PassRole entirely.
